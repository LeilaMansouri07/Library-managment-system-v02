# Library Management System v02

A simple **console-based Library Management System** written in **Java** with **Maven**.  
This project demonstrates basic Object-Oriented Programming (OOP) principles and provides functionality to manage books, members, and borrow records.

---

## Features
- Add, edit, and remove books  
- Register and remove library members  
- View list of books and members  
- Borrow and return books  

---

## Implementation Details
- Uses **Java Collections Framework** (`ArrayList`, `LinkedList`, etc.) to store and manage books and members  
- Demonstrates OOP principles such as encapsulation, inheritance, and polymorphism  
- Organized with packages for better modularity (e.g., entities, services, exceptions)  

---

## Technologies Used
- **Java** (JDK 8 or higher)  
- **Maven** (for build and dependency management)
